# 2026-08-13

## 接口轮询重试机制：连续失败 3 次即停表
- 新增 `src/hooks/usePolling.ts`：`active + visible` 时才周期执行 `task`；`task` 连续失败 `maxConsecutiveFailures`（默认 3）次后自动 `clearInterval` 停表，不再空转烧流量；成功一次即清零计数；`active/visible` 变化会重置计数并尝试恢复。task 返回 `false` 或 reject 均算失败。
- `pages/scripts/index.tsx`、`pages/scriptDetail/index.tsx` 两处 `import-status` 轮询改用 `usePolling`，移除了各自内联的 `timerRef` 轮询逻辑；`loadStatuses`/`loadStatus` 改为返回 `boolean`（成功 true / 失败 false），失败时不再静默吞掉、转为计入失败计数。
- 放弃轮询时给出提示：列表页置 `errorMsg="状态刷新已停止（连续多次失败），请下拉重试"`，详情页 `showToast` 提示下拉重试。恢复需用户手动下拉刷新（重新激活 active 即可重置计数）。
- 验收：`tsc --noEmit` 对 `src/` 零新增报错（仅存 `auth.tsx` 一处无关 `Profile` 未用导入告警）。
