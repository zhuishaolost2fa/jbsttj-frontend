## 经验补充：H5 构建也会触发 safe-delete 拦截
- 此前笔记称「H5 构建无此问题」不准确：只要 dist 里有旧文件，H5 build 同样在 emptyOutputDir 处被 genie-safe-delete shim 拦截。`NODE_OPTIONS= npm run build:h5` 是稳定解法（已更正 MEMORY.md）。
