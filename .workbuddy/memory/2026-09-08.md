## 故事还原 tab 出现「tab 标签」—— 根因

用户切换到「故事还原」tab 时看到一排 tab 标签（全部 / 时间线 / 真相还原 / 角色背景 / 线索关联 / 结局收束）。

**根因**：`src/components/StoryPanel/index.tsx` 的 `TYPE_CHIPS`，仅在「无合成文章」时渲染。`hasSynthesis = synthesisStatus==='ready' && !!overview` 决定走哪条分支：
- 有合成 → 渲染合成文章（chips 藏进抽屉）
- 无合成 → 直接渲染 `renderDetailsList()` → 顶上一排 chips + 卡片列表

不是渲染错误，是**产品设计的降级路径**。但视觉上 chips 确实像 tab 标签。

**附带发现：后端合成接口空 overview 问题**。实测线上 7 个 has_guide=true 剧本，`GET /api/v1/dm-guide/synthesis` 全部返回 `synthesisStatus:"ready"` + `overview:{全空字符串}` + `documentId:null`（只有 `mao-dao-mou-sha-xun-huan` 真有内容）。这意味着前端 `hasSynthesis=true` → 渲染空白合成文章 + 一个孤零零的「展开全部 0 张故事碎片」按钮。视觉上很怪。

→ 前端防御性修法：把 `hasSynthesis` 改成要求 overview 至少一节非空，否则降级到 chips+列表。

### ⚠️ 新发现（未处理，等用户拍板）
**站点 https 完全不通**（curl 返回 000、Node fetch 超时、WebFetch 也失败），只有 http 可用。但 `gen-seo-pages.mjs` 的 `SITE` 默认 `https://www.jbs-ttj.store` → **线上 sitemap 里 15 条 URL 全是 https，当前全是死链**，推给 Bing 也抓不到。
`SITE` 支持 `SEO_SITE_ORIGIN` 环境变量覆盖，但 **gen-seo-pages.mjs 不加载 .env**（无 dotenv），只在 process.env 里读，需显式传参或在 CI 里设。
（.env 注释里用户自己写过「等备案 + HTTPS 后再切回 https」，所以 sitemap 写 https 可能是有意为之。）
