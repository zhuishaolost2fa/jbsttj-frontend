## 问答目录直答消息加「追问下一问」

用户希望在问答模块里：**从问答目录找到问题并发起提问后**，在该消息下方加一个「追问」按钮，问的问题是目录里的下一个；点之后直接追问。

### 设计

- 目录树 (`fetchQaTitleChain` 返回的 `QATitleChain.titles`，每章含 `qa: QATitleItem[]` + `children`) → DFS 平展成 `flatCatalog: { item, path }[]`，path 携带章节面包屑。
- 派生 `followupMap: Record<qaId, FlatCatalogEntry>`：每条非末尾 QA 指向平展数组里的下一项；末尾问答不进入表，对应的"追问"按钮自动不显示（点了也没反应，避免尴尬）。
- `ChatMessage` 加 `qaId?: string`（仅目录直答时写）；assistant 气泡渲染时如果 `m.qaId && followupMap[m.qaId]`，就在出处下方加一行"追问下一问：xxx →"可点块。
- 追问复用 `handleCatalogAsk(next.item, next.path)` —— 与初次发起目录提问走同一链路（标"手册原文 · 100%"、出处、章节路径一致）。
- 仅 `qaId` 触发；走 ask、AI、引导问答直出的消息没有 `qaId`，不会显示追问按钮。

### 改动文件

- `src/pages/scriptDetail/index.tsx`：
  - 新增 `FlatCatalogEntry` 类型；`ChatMessage` 加 `qaId` 字段。
  - 新增 `useMemo` 派生 `flatCatalog`、`followupMap`。
  - `handleCatalogAsk` 内 assistant 消息写入 `qaId: item.id`。
  - 新增 `handleFollowupAsk(qaId)`。
  - 气泡渲染块末尾加 `followup-block` 视图。
- `src/pages/scriptDetail/index.less`：新增 `.followup-block` / `.followup-label` / `.followup-q` / `.followup-icon`（沿用 `@fill`/`@ink`/`@ink-faint`，与设计体系一致）。
