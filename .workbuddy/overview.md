# 全站视觉改版：墨 / 白 / 品牌黄三色体系

改造日期：2026-09-09

## 一、设计令牌（新增，全站唯一色源）

- `src/styles/tokens.less` —— less 变量（编译期替换，小程序端可靠）。所有 `.less` 顶部 `@import` 引入。
- `src/styles/tokens.ts` —— 同色值的 TS 常量，供 `.tsx` 内联样式使用（小程序端拿不到 less 变量和 CSS 变量）。

三色：`@ink #181818` · `@paper #ffffff` · `@accent #FFD342`
派生：`@ink-2/-soft/-mute/-faint`、`@line/-mid/-strong`、`@canvas/-fill/-fill-deep`、`@accent-deep/-soft/-line`、`@danger`（克制红，仅用于删除/错误）
间距：`@sp-1 ~ @sp-12`（4 的倍数）；圆角 `@r-xs ~ @r-pill`；阴影 `@shadow-sm/md/lg`（一律基于 ink）。

## 二、配色替换

- 旧主色 `#5b7cfa / #8b5cf6`（蓝紫渐变）→ `@ink` / `@accent`，83 + 29 处全部替换。
- 次级灰 `#9aa0ae / #b6bac6 / #6b7080 …` → 统一五档中性灰。
- 旧蓝调 tint 底（`#eef1ff / #f0f7ff …`）→ 黄 tint `@accent-soft`。
- 绿色（成功）、橙色（警示）、微信绿 → 归入 ink / accent。
- 保留唯一语义色 `@danger #C0392B`（删除、失败），`@danger-soft` 作浅底。
- **所有同色渐变压平成纯色**（渐变在这个配色里只会显旧）。
- 校验：`dist/**.css` 与 `dist/**.wxss` 已无 `5b7cfa / 8b5cf6 / 9aa0ae` 残留。

## 三、主 CTA 统一形态

主操作 = 品牌黄底 + 墨字 + 8px 圆角 + 无彩色投影（AppButton primary、登录提交、发消息、表单确认、空态按钮、导入按钮）。
次级 = 白底 + 细描边。禁用 = 灰底 + 灰字。
深色底（头像编辑器工具栏、墨底卡片）上的主操作同样用黄块，保证一眼可辨。

## 五、间距与层级

- 页面底统一 `@canvas #F7F7F7`，卡片白底 + `@line` 细描边，取代原来的"灰卡片 + 彩色投影"。
- 卡片间距 12px、内边距 16px、区块间距 16px、页头下方 16px、空态上下 48/64px，全部走 `@sp-*`。
